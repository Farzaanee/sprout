# Built modules

Part of the [Sprout architecture docs](README.md). See the [overview](1.%20overview.md) for goals and dependency direction.

| Module | Responsibility | Interface | Errors | Phase added |
|---|---|---|---|---|
| `config.py` | Env and `.env` into frozen `Settings` | `get_settings()`, `require_*_key()` | `MissingConfigError` | 0 |
| `models.py` | Taxonomy, `Sourced[T]`, `CompanyProfile` (`extra="forbid"`) | Pydantic classes | `ValidationError` for unsourced values, naive datetimes | 0 |
| `sources/http.py` | Single network entry point | `HttpClient.get`, `DiskCache`, rate limiters | `FetchError`; 4xx (not 429) no retry; 429/5xx retry 4 times with backoff | 1 |
| `sources/companies_house.py` | Registry client | `search`, `advanced_search`, `get_company`, `filing_history`, `active_officer_count` (5, D34) | `FetchError` | 1 |
| `sources/rss.py` | Feeds to `NewsItem` | `fetch_feed`, `parse_feed`, `normalise_url` | One bad feed doesn't stop others | 1 |
| `sources/web.py` | Polite, safe page fetch | `WebFetcher.fetch`, `html_to_text` (Phase 4 adds `UrlPolicy`, see the [Phase 4 page](phases/phase-4-evals-guardrails.md)) | `FetchBlockedError` | 1 |
| `candidates.py` | Name and SIC heuristic; shell/non-AI pre-screen (5, D34) | `assess()`, `passes_prescreen()` | none | 1 |
| `db.py` | SQLModel tables and writes | `init_db` (create tables, then additive `ALTER TABLE` for missing nullable columns), `upsert_company`, `save_fact`, `add_news_items`, `logged_run`, `save_profile`, `save_funding_rounds`, `delete_profile`, `add_company_by_number`. Tables: `company`, `fact`, `funding_round` (2), `news_item`, `run_log`, `run_log_step` (3) | failures logged in `run_log` with a `failure_category`, re-raised; non-additive schema change raises `RuntimeError` telling you to reset the DB | 1 |
| `ingest.py` | Phase 1 orchestration | `python -m sprout.ingest` | exit code 1 on failed feeds | 1 |
| `app/queries.py` | Streamlit-free read queries | `search_companies`, `company_facts`, `company_funding_rounds`, `search_news`, `parse_phases`; Phase 3: `enrich_runs`, `failure_counts`, `cost_trend`, `daily_outcomes`, `run_steps` | none | Pre-6 (built ahead of schedule alongside the progress/test console); observability queries 3 |
| `costs.py` | Price table, `Usage`, USD cost (pure); per-run enrichment batch size (5, D34) | `PRICES`, `WEB_SEARCH_USD_EACH`, `Usage`, `cost_usd`, `enrichment_batch_size` | `UnknownModelError` for an unpriced model (fails closed) | 2 |
| `agents/loop.py` | Generic tool-use loop; the only pipeline module importing `anthropic` | `run_agent`, `make_client`, `Budget`, `Tool`, `ToolOutcome`, `LoopResult`, `StepRecord` (3) | never raises for API, tool or model problems: returns a `LoopResult.stop` code; `ValueError` from `Budget` for bad caps; `UnknownModelError` before the first call | 2 |
| `agents/tools.py` | Tool specs, handlers, seen-URL ledger, untrusted wrapping | `build_tools`, `SourceLedger`, `wrap_untrusted` | handlers return error outcomes, never raise into the loop | 2 |
| `agents/enrich.py` | Prompt, `submit_profile` schema and validation, persistence, `enrich` run_log row, CLI | `enrich_company`, `enrich_with_result`, `validate_submission`, `submit_profile_schema`, `resolve_company`, `main` | `EnrichmentFailed(stop, cost_usd)` on any non-success; `CompanyNotFound` for the CLI; exit 0 ok, 1 any skip or failure, 2 missing Anthropic key | 2 |
| `enrich.py` | `python -m sprout.enrich` shim | `main` re-export | see `agents/enrich.py` | 2 |
| `failures.py` | `FailureCategory` (8 values), `failure_category_for(stop)` (pure) | `FailureCategory`, `failure_category_for` | none | 3 |
| `app/dashboard.py` | Streamlit tabs (entry `streamlit_app.py`): Progress, Companies, News, Observability, Run & test (only with `SPROUT_ENABLE_ACTIONS=1`) | `render_*` functions over `app/queries.py` | empty and partial states render a message, never raise | Pre-6; Observability tab 3 |

Phase 2's built interfaces (exact signatures), the loop contract table, and the planned Phase 5/7 module stubs are on the [Phase 2 page](phases/phase-2-enrichment.md) and [Phase 5 page](phases/phase-5-multi-agent.md). The [data model](2.%20data-model.md) (section 3.4) covers the SQLite schema these modules read and write.
