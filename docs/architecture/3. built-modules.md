# Built modules

Part of the [Sprout architecture docs](README.md). See the [overview](1.%20overview.md) for goals and dependency direction.

The database models use `DatabaseModel.metadata`, an isolated SQLAlchemy registry, rather than
`SQLModel.metadata`. Each module import gets its own mappings, including after a Streamlit reload.

Phase 5 (built) changed these modules in place (the `(5)` markers above): `sources/web.py` (`UrlPolicy`), `sources/http.py` (`max_seconds`), `agents/tools.py`, `agents/enrich.py` (`sources` in `stats`, tool-set check), `agents/loop.py` (notices name the terminal tool) and `costs.py`. `evals/` is new at the repo root, outside the package: `golden.py`, `metrics.py`, `judge.py`, `fixtures.py`, `injection.py`, `run_evals.py` (`python -m evals.run_evals`). See the [Phase 5 page](phases/phase-5-evals-guardrails.md).

Phase 6 (built) added the six rows marked 6 above and changed in place: `db.py`, `costs.py`, `agents/loop.py`, `agents/tools.py`, `agents/enrich.py` (run recording moved to `agents/common.py`), `sources/http.py` (`DiskCache.put` unique temp name), `models.py` (`NewsKind`). See the [Phase 6 page](phases/phase-6-multi-agent.md#changes-to-existing-code-built).

Phase 7 (built, except the deliberately skipped Ask box) added the `queries.py` functions and the `app/` modules marked 7 above and moved `bar_chart` and the engine and session helpers out of `app/dashboard.py` into `app/ui.py`. See the [Phase 7 page](phases/phase-7-dashboard.md).

Phase 3's built interfaces (exact signatures) and the loop contract table are on the [Phase 3 page](phases/phase-3-enrichment.md). The [data model](2.%20data-model.md) covers the SQLite schema these modules read and write.
